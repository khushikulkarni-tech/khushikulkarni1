## Featured Projects

### 🧾 Intelligent Document Processing (IDP) System
`Python` `FastAPI` `Tesseract OCR` `OpenCV` `Pandas` `SQL` `Git`

An end-to-end document intelligence pipeline built to convert unstructured scanned/document input into clean, structured, analytics-ready data.

- **Document ingestion** — accepts incoming documents and images for processing
- **Image preprocessing** — uses OpenCV to prepare images (denoising, thresholding, alignment) for accurate OCR
- **OCR extraction** — Tesseract OCR extracts raw text from processed documents
- **Information extraction** — parses extracted text to identify relevant fields and entities
- **Text/data normalization** — standardizes formats, casing, and structure across extracted fields
- **Cleaning and validation** — applies data cleaning and validation rules using Pandas before persistence
- **Structured data generation** — converts unstructured OCR output into structured records ready for storage/analysis
- **FastAPI REST endpoints** — exposes ingestion, processing, and retrieval functionality via clean REST APIs
- **Exception handling and logging** — built-in error handling and logging for traceability and reliability
- **Downstream reporting/analytics** — structured output feeds into SQL-based reporting and analysis

### 🚨 AI-Powered Crowd Density & Emergency Alert System
`Python` `YOLOv8` `DeepSORT` `LSTM` `OpenCV` `Flask` `MySQL`

A real-time computer vision system for crowd monitoring, stampede-risk prediction, and automated emergency alerting.

- **Real-time person detection** — YOLOv8 detects individuals in live/recorded video feeds
- **Object tracking** — DeepSORT maintains consistent identity tracking of detected individuals across frames
- **Crowd-density analysis** — computes density metrics from tracked object counts and spatial distribution
- **Time-series feature generation** — converts frame-by-frame density data into time-series features
- **LSTM predictive modelling** — an LSTM model is trained on time-series features to predict stampede/crowd-risk trends
- **ML inference** — real-time inference pipeline scores incoming video feed data against the trained model
- **Automated emergency alerts** — triggers alerts automatically when risk thresholds are crossed
- **Flask APIs** — serves detection, tracking, and prediction results through Flask-based endpoints
- **MySQL persistence** — stores detection events, density metrics, and alert logs
- **Real-time data flow** — designed for continuous ingestion and low-latency processing across the pipeline

**Repository:** [Crowd-density-stampede-using-YOLOv8](https://github.com/khushikulkarni-tech/Crowd-density-stampede-using-YOLOv8)
